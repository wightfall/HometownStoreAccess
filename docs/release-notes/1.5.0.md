Support for the game's 1.7.12 update (weather, the storage list with deliveries, shelf slot locks, the Customers pages, money on the map), section headings in every list, steadier focus everywhere, and a fixed installer.

## What's new

- Weather: rain and fog, new in the game, are said when they start, change or stop, for example "Weather: heavy rain"; T says the weather too, and the new setting Weather turns the announcement off
- Every list with sections has section headings, as the mod settings do: Page Up and Page Down land on the heading, for example "Basket, 3 items, heading"; the main menu, the options, the map, shops, shelves and the storage list all have them
- A screen opens on its first entry with its section's name, and a section's name is said whenever you come into it without its heading (a letter, End, a screen opening)
- The credits are in sections: Developed by, Core team, Collaborators, Testers and Special thanks
- The storage list (All stock, from the shop or the map) reads the game's new lines: the storage slots in use and the goods waiting on the delivery truck, and each product says how many wait for delivery
- Shelf slots can be locked to a kind of goods, as the game now allows: each slot is followed by its lock, a check box
- The Customers panel has the game's new pages, Customer groups and Employees (the demo has no employees yet)
- The move-everything buttons say what they moved, for example "Moved to the shelf: Candy: 22"
- The map says your money, as the game now shows it
- The installer opens on its status box, or on the new What's new box when it updates an older version

## Game update 1.7.12

- On game 1.7.12, version 1.4.5 said vehicle names wrongly in Thai (for example "Foots" instead of "ตีนเปล่า"); the mod now finds the game's text tables by name, so a game update cannot shift them again
- The shop upgrade is said when the game really does it, as the day's summary opens; the game now only books it when you agree to it, and the mod said it too early, with the old level
- A popup's buttons work at once: the game now locks them for up to half a second while the popup opens, and an Enter in that moment was lost; the mod now waits for the button
- An event that asks for money is marked on the map only once you have that much, as the game now does
- Three English captions the game now translates itself are no longer replaced; one of them called the storage panel "All stock" in English

## Bug fixes

- The delivery truck is announced whenever the game shows it. Goods bought on the map in the evening come as soon as you close the map (the game's tutorial says the next morning, but the game sends the truck at once); the mod said nothing then
- Enter on a sound cue (the key list and the cue volumes) plays only that cue, without the list's click
- The installer took the installed version from its own record and compared updates with its own version, so an old installer said "you have 1.3.1" with 1.4.5 installed. It now reads the version from the mod's DLL, offers an update only when it is newer than what you have, and asks before installing an older version
- When an entry goes away (goods moved, a basket line removed), the focus goes to the nearest entry in the same section and you hear it; before, it could land silently in another section
- After placing or cancelling a building, the build list is back on the blueprint you used
- After choosing a machine's recipe, the focus is back on Change recipe, and after the save name box closes, on New save
- Ctrl+Up and Ctrl+Down in the event journal follow Wrap around, and the journal reads the new view's first event after switching
- The game's sliders (the volumes in Options) play the edge sound at their ends
- The key list keeps your line when the controller's section moves
- A shelf whose locked slots are all empty is said to be empty, and picking it up no longer asks about goods that are not there

## Game text

- 13 more spelling mistakes in the game's Thai text are fixed, such as "ประเทภ", "ปฎิเสธ", "สถาณี" and doubled marks; the game has not fixed the earlier 19, so those fixes stay
- The 127 new lines of game version 1.7.12 (the shaman and the Kumara spirit, the shop's level 4 upgrade, the storage list) are translated into Japanese, Chinese and Indonesian
- The Customers panel's new English captions (Employees, No employees yet) are said in your language

## Other

- F1 help, the README and all five languages updated; 311 unit tests
- New test commands for developers: weather, items, upgrade and setting

## Install

Close the game, download HometownStoreAccessInstaller.exe and run it.
Or extract HometownStoreAccess-1.5.0.zip into the game folder, next to HometownStore.exe.
Start the game from Steam and press F1 for help.
